Run it yourself

Everything here is reproducible on a laptop — a local kind cluster, a local model, no cloud account.

git clone https://github.com/pezeonyim/k8s-incident-responder
cd k8s-incident-responder && python3 -m venv .venv && source .venv/bin/activate
./scripts/dev.sh install && ./scripts/dev.sh cluster-up
kubectl apply -f manifests/sample-app.yaml
kubectl apply -f manifests/rbac.yaml

python src/server.py        # control panel at http://127.0.0.1:8420
python eval/harness.py --trials 10
